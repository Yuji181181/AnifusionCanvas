# AnifusionCanvas 開発ロードマップ

最終更新: 2026-05-18 JST

## 方針チェックリスト

- [x] 公開 UI は「AI中割り」と「Inpainting」に絞る
- [x] 手動編集と書き出しは既存コードや API を残し、通常のフロントエンド導線から外す
- [x] 細かいテスト整備、CI 拡張、手動編集、書き出し改善は優先しない
- [ ] 本番環境で AI中割りと Inpainting が普通に使えることを確認する

## 公開スコープ

- [x] AI中割り: 2枚の原画から ToonCrafter で中割りフレームを生成する
- [x] Inpainting: 生成済みフレームを選び、マスクとプロンプトで部分修正する
- [x] タイムライン: 生成・修正済みフレームを確認し、Inpainting 対象を選ぶ
- [x] 手動編集: UI 非表示。既存実装は残す
- [x] 書き出し: UI 非表示。既存実装は残す

## 実装済み

- [x] Cloudflare Pages の React SPA と Cloud Run の Go API による本番構成
- [x] Replicate 実推論モードでの ToonCrafter / SDXL Inpainting 呼び出し
- [x] R2 公開 URL を使った Replicate 参照用画像保存
- [x] TiDB のフレーム URL 長尺化マイグレーション
- [x] AI中割りの開始、ジョブ進捗表示、タイムライン反映
- [x] ToonCrafter の配列形式出力を動画 URL として扱う修正
- [x] Inpainting の対象フレーム選択、マスク作成、修正ジョブ開始
- [x] 失敗時の再試行パネル
- [x] 手動編集 / 書き出し UI の非表示化
- [x] `/step3`、`/step3/edit`、`/export` の `/step1` リダイレクト
- [x] AI中割り / Inpainting 実行前に課金と待ち時間の目安を表示
- [x] README と運用手順を現スコープへ更新

- [ ] 本番環境で Inpainting を 1 回通し、修正結果がタイムラインへ反映されることを確認する

## P1: 使い勝手の最低限の改善

- [x] 生成中・修正中の待ち時間表示をわかりやすくする
- [x] Replicate の課金が発生する操作であることを必要十分に伝える
- [x] 入力画像が大きすぎる、または形式が不正な場合の案内を改善する
- [ ] マスク未描画や対象フレーム未選択時の案内をさらにわかりやすくする
- [ ] 生成結果が空、または Replicate 出力形式が想定外だった場合の診断情報を運用ログで確認する

## P2: 運用安定化

- [x] 本番デプロイ手順と環境変数チェックリストを用意する
- [x] 既存の最小検証だけを維持し、テストや CI の新規拡張を行わない方針にする
- [ ] 本番 smoke test の実行日、結果、失敗時の対応を `docs/operations-guide.md` に追記する
