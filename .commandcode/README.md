# AI Agent Configuration

このディレクトリは、AnifusionCanvas の開発を自律的に進めるための AI agent 設定を格納する。

## 役割

- `planner`: 要件理解、探索、分解、実行計画の作成
- `generater`: 実装、編集、テスト追加、構成変更
- `evaluer`: 品質評価、要件適合性確認、リスク検出、受け入れ判定

## ディレクトリ

- `agents/`: 各エージェントの役割定義
- `skills/`: エージェントが再利用する手順テンプレート
- `runtime/`: タスクの受け渡し、判定基準、オーケストレーション設定
- `templates/`: タスク計画、レビュー、実装依頼のテンプレート

## 基本フロー

1. `planner` が要件を分析し、タスクを分解する
2. `generater` が計画に基づいてコード・設定・文書を更新する
3. `evaluer` が要件充足、品質、テスト、リスクを評価する
4. 問題があれば `planner` に差し戻し、再計画または `generater` に再実装を依頼する

## 原則

- 目的、AIモデル選定、3ステップの編集ワークフローは明示的な指示がない限り変更しない
- 変更前に既存ファイルを読む
- 小さな変更でも検証方法を決める
- 不明点は放置せず、仮説・前提・未確定事項を明示する
